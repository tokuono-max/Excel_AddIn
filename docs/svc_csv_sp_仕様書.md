# svc_csv_sp 機能仕様書（行範囲分割方式）

**対象**: CSVファイル分割（選択行による範囲分割・ファイル保存）  
**作成日**: 2026-03-06  
**目的**: 機能概要・UI・画面遷移・ログを一括で定義し、実装の正本とする。

---

## 1. 機能概要

Excel アクティブシートの、**単独または複数で選択されたセル行（選択行）** を境界として、シートを分割し、分割単位ごとに CSV ファイルとして保存する機能である。

- **入力**: 機能起動時点の Excel アクティブシート、およびユーザーが指定する分割範囲（開始行・終了行の編集可能な一覧）
- **出力**: 指定フォルダに、分割数に応じた複数の CSV ファイル（UTF-8 BOM、拡張子 `.csv`）

---

## 2. 前提条件

| 項目 | 内容 |
|------|------|
| **アクティブシート** | 機能起動時点の Excel アクティブシートを対象とする |
| **ヘッダ** | アクティブシートの **1 行目をヘッダ** とする。各分割ファイルの 1 行目にもヘッダを投入する |

---

## 2.1 アクティブシートにデータがないときの挙動

分割機能は **「2 行以上・1 列以上」のデータ** があることを前提とする。データが不足している場合などは **分割画面は開かず**、**Excel 中央にワーニング通知**を表示する。

| 条件 | 挙動 | 表示メッセージ（例） |
|------|------|----------------------|
| シートを特定できない | ワーニング表示 → OK で閉じる | 「シートを特定できませんでした。」 |
| 使用範囲が取得できない | ワーニング表示 → OK で閉じる | 「使用範囲を取得できませんでした。」 |
| 行/列を取得できない | ワーニング表示 → OK で閉じる | 「行/列を取得できませんでした。」 |
| 行数 &lt; 2 または 列数 &lt; 1 | ワーニング表示 → OK で閉じる | 「データが不足しています（2行以上・1列以上必要）。」 |
| 分割範囲が 1 件も組み立てられない | ワーニング表示 → OK で閉じる | 「分割範囲を組み立てられませんでした。」 |

**ワーニング通知の仕様**

- **表示位置**: Excel ウィンドウの中央
- **表示**: 常に Excel の前面（Excel と親子関係）。他アプリの背面に隠れる
- **Excel 操作**: 表示中は無効、OK で閉じたあとは有効に戻す
- タイトルは「ファイル分割」。config の `SCREENS.WARNING` で変更可能
- **MSG**: 表示メッセージ。改行は JSON で `\n`（パースで改行になる）または `\\n`（リテラルとして残る場合はコードで改行に変換）で指定可能
- **設定読込**: `config/ui_csv_sp.json` は機能起動時（各画面表示時に `create_dialog` 経由で読込）。core_cst がファイル mtime でキャッシュ。

---

## 3. 行分割の定義

- **選択行**: ユーザーが単独または複数で選択したセル行。各行は「分割範囲の開始行」の候補とする。
- **分割範囲**:
  - **開始行**: その選択行の行番号。ただし **最初の分割** の開始行は「シート先頭行（ヘッダ行を除く＝2 行目）」とする。
  - **終了行**: 「次の選択行 − 1」。次の選択行がない場合は **シートのデータ領域の最終行** とする。
- **分割範囲の編集**: UI 上で行数（分割数）を **追加・削減** でき、各分割の開始行・終了行を編集可能とする。

## 4. ファイル保存

| 項目 | 内容 |
|------|------|
| **保存の流れ** | 保存先フォルダ選択画面でフォルダを指定後、分割単位ごとに 1 行目にヘッダを付与してファイルに保存する |
| **保存先フォルダ選択** | 常に分割画面の前面に表示。**フォルダのみ選択**（ファイルを選ばなくても、開いているフォルダを保存先とする）。config の `DIALOGS.FOLDER` でタイトル・デフォルトベースファイル名を定義。 |
| **ベースファイル名** | 未指定時は **Excel アクティブシート名**。config の `DEFAULT_BASE_FILENAME` で上書き可能。 |
| **分割時のファイル名** | ベース名の末尾に **"_分割連番"** を付ける。例: 3 分割 → `ベース名_1.csv`, `ベース名_2.csv`, `ベース名_3.csv` |
| **ファイルフォーマット** | **UTF-8（BOM）**、拡張子 **`.csv`** |

### 4.1 ファイル名・パス（日本語等）

| 項目 | 内容 |
|------|------|
| **日本語・Unicode** | Windows および本アドインでは、**保存先のファイル名・フォルダパスに日本語（Unicode）を使用できる**。ベースファイル名やフォルダに日本語を指定してよい |
| **注意** | 一部のレガシー環境や他ツールでは Unicode パスで問題が出る場合がある。その場合は英数字のパスを利用すること |

## 5. UI の種類および画面遷移

| 項目 | 内容 |
|------|------|
| **UI 総称** | サブ画面 |
| **UI 種類** | 分割画面、フォルダ選択画面、進捗画面、終了通知 |
| **画面遷移** | Excel リボン → **分割画面** → **フォルダ選択画面** → **進捗画面** → **終了画面** → Excel |

### 5.1 各 UI の挙動

| UI | 開くタイミング | 閉じるタイミング |
|----|----------------|------------------|
| **分割画面** | Excel リボン選択で開く | 終了通知が閉じるときに一緒に閉じる |
| **保存先フォルダ画面** | 分割画面の「分割開始」ボタン選択で開く。**ファイル名は表示のみ**（参照でフォルダのみ選択可能） | キャンセルまたは OK で閉じる |
| **進捗画面** | 保存先フォルダ選択後（OK 後）、**分割画面を閉じずに**その前面に表示 | 各工程表示後、進捗 100% から **1 秒間** 経過後に閉じる |
| **終了通知** | 進捗画面 100% の **1 秒後** に表示 | OK で閉じる。閉じると同時に **分割画面も閉じ**、Excel 操作を有効にして Excel へ戻る |

## 6. UI 構成（分割画面）

大きなブロックとして以下を持つ。

### 6.1 機能説明

- 機能の概要を表示する。

### 6.2 分割詳細（テーブル）

| 列名 | 説明 |
|------|------|
| （列名） | 分割の識別（例: 列番号や No. など。仕様では「列名」と記載） |
| **保存ファイル名** | `シート名_分割連番`（拡張子は表示しない） |
| **分割開始行** | その分割の開始行番号。<br>※ 最初の分割の場合は「シート先頭行（ヘッダ行除く＝2 行目）」を開始行とする |
| **分割終了行** | その分割の終了行番号。<br>※ 複数選択時は「次の選択行 − 1」。次の選択行がなければシートのデータ領域最終行 |
| **分割行数** | （終了行 − 開始行）＋ 1 |

- 分割範囲は UI で **行の追加・削減** が可能とする。

### 6.3 制御ボタン

| ボタン | 動作 |
|--------|------|
| **追加** | 分割を編集できる行を 1 行追加する |
| **削減** | 最後の分割編集行を 1 行削除する |
| **分割開始** | 分割処理を実行し、分割ファイルを保存する（押下でフォルダ選択画面へ） |
| **キャンセル** | 分割画面を閉じ、Excel へ戻る |

## 7. UI 表示の共通仕様

| 項目 | 内容 |
|------|------|
| **Excel 操作** | UI 表示中は Excel 操作を無効、Excel へ戻る時に操作を有効とする |
| **表示位置** | Excel ウィンドウの中央に表示する |
| **前面表示** | 常に Excel の前面に表示（Excel と親子関係）。他アプリのウィンドウが前面の場合は後ろに隠れる（TOPMOST は Excel の前のみ） |

### 7.1 共通仕様（全画面で統一）

| 項目 | 内容 |
|------|------|
| **改行** | 各画面に表示する文字列（MSG、MSG_HEADER 等）では、JSON の `\n` またはリテラル `\\n` により改行を指定できる。コード側で `_normalize_message_newlines` により統一処理する。 |
| **アイコンと文字列** | アイコンと文字列の位置関係は **アイコンの下に文字列** とする（縦並び）。ワーニング・完了通知などで統一する。 |
| **リスト背景** | リスト表示（完了通知のファイル一覧等）の背景色は、白ではなく **画面（ウィンドウ）の背景色と同じ** とする。config の `LIST_BG_SAME_AS_WINDOW: true` で制御する。 |

## 8. 進捗画面

- 分割処理中は進捗画面を表示し、処理の進捗を視覚化する。
- **進捗バー左上端** の表示フォーマット:  
  **実施工程番号/総工程番号 実施中処理名 [保存中の分割ファイル名]**
- **進捗バー右下端**: **N/M**（例: 現在 N 番目 / 全 M 分割）

## 9. ログ出力

- **使用モジュール**: `core.core_log`（`get_logger`）を使用する。
- **内容**: 内部の進捗処理の状況、および「シート名を何分割して、どのフォルダに、どのファイル名で保存したか」を出力する。
- **フォーマット**: 既存のログ出力に合わせる（時刻・レベル・モジュール名・メッセージ形式など）。出力先は `core_log` の既定（例: `hc_csv.log`）に従う。

## 11. 現行実装との差分（実装時メモ）

本仕様は **「選択行による範囲分割」** である。現行の **「キー列でグループ分割」** とは別方式のため、以下の差分がある。

| 観点 | 現行実装 | 本仕様 |
|------|----------|--------|
| **分割の基準** | キー列の値でグループ化し、グループごとに 1 ファイル | 選択行を境界にした「開始行〜終了行」の範囲を 1 分割とし、分割数だけファイルを出力 |
| **UI 画面** | 1 画面（キー列選択＋出力先フォルダ） | 分割画面（テーブル＋追加/削減/分割開始/キャンセル）→ フォルダ選択画面 → 進捗 → 終了通知 |
| **分割範囲** | ユーザーはキー列のみ指定。範囲は自動 | ユーザーが選択行から初期化し、テーブルで開始行・終了行を編集・追加・削減可能 |
| **ファイル名** | キー値ごとに `{キー値}.csv` | ベース名（シート名またはユーザー入力）＋ `_1`, `_2`, … ＋ `.csv` |
| **進捗** | 進捗画面なし（同期的に分割実行） | 進捗画面を表示し、工程番号/総工程・処理名・保存中ファイル名・N/M を表示。100% 後 1 秒で閉じる |
| **終了** | ステータスバー通知のみ | 終了通知ダイアログ表示 → OK で終了通知と分割画面を閉じ、Excel 有効化 |
| **分割画面のライフサイクル** | なし（1 回の設定ダイアログで完結） | リボンで開き、終了通知を閉じるまで開いたまま |

実装時は、`svc_csv_sp.split_csv` の入口で「アクティブシートの選択行」を取得し、その行番号から分割範囲（開始行・終了行）の初期リストを組み立て、`ui_csv_sp` に渡す。UI は分割画面を先に表示し、ユーザーが「分割開始」を押したらフォルダ選択画面を出し、OK 後に進捗付きで保存処理を行う。
