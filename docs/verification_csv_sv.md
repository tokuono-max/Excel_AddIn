# CSV保存 (csv_sv) 動作確認手順

**対象**: `svc_csv_sv` + `ui_qt.ui_csv_sv`（新方式）  
**確認日**: 2026-03-05

---

## 1. 事前準備

| 項目 | 内容 |
|------|------|
| Excel | アドイン読み込み済みの Excel を起動する。 |
| シート | アクティブブックに、CSV として保存したいデータが入力されたシートがあること。 |
| 設定ファイル | `config/ui_csv_sv.json` が存在し、MAIN / SCREENS.PROGRESS が定義されていること。 |
| UI サーバ | 初回実行時に自動起動する。手動起動は不要。 |

---

## 2. 呼び出し経路の確認

- **VBA / リボン**: 「CSV保存」などから `hc_main.invoke(action='save_csv', target_hwnd=..., sheet_id=...)` が呼ばれる。
- **hc_main**: `_call_svc_server(ACTION_CSV_SV, book_ptr=..., sheet_id=...)` で svc_server に委譲。
- **svc_server**: `svc.svc_csv_sv.save_csv(book, sheet_id)` を実行。
- **svc_csv_sv**: 保存先選択を UI サーバへ依頼（IPC）→ 結果受信後に `_do_save_csv` で保存実行。

## 4. 処理フロー（参考）

1. **保存先選択**: UI サーバが `ui_csv_sv.create_dialog(action="csv_sv")` で `_CsvSaveFileDialog` を生成し、`getSaveFileName`（ネイティブ）で保存先を取得。
2. **結果の受け渡し**: ユーザーが「保存」を押すと、`status=OK` と `path=<保存先パス>` が result_path の pickle に書き込まれる。
3. **保存実行**: `svc_csv_sv._watch_result` が result_path を検知し、`_do_save_csv` を呼ぶ。
4. **進捗**: 保存実行前に進捗 UI を起動し、`progress_sv_<sheet_id>.pkl` で「データ読込中」「ファイル保存中」「完了」を更新。
5. **通知**: `core_stat.set_notify_retv` と `StatusBar` で保存結果を通知。

---

## 5. 確認時の注意（csv_ld との差）

- **ファイル選択ダイアログ**: 現状、親ウィジェットに Excel を紐付けていないため、ダイアログ表示中も Excel 操作は有効。csv_ld のように「表示中は Excel 操作無効」が必要な場合は、同様に `enable_excel_window` と親ウィジェットの設定を検討する。
- **進捗の枠だけ残る**: csv_ld で実施した `no_native_window` や `deleteLater()` は、csv_sv の進捗ダイアログでは未適用。同様の事象が出た場合は、csv_ld と同様の対策を検討する。

## 6. ログで確認できること

- `[START] save_csv (svc_csv_sv)` … 保存処理開始。
- `[QT_UI_SERVER] csv_sv request submitted` … UI サーバへ保存先選択を依頼。
- `[READY_UI] csv_sv` … UI サーバがダイアログを表示したタイミング。
- `[UI_RESULT] csv_sv status=OK path_len=...` … ユーザーが保存先を指定した結果。
- `Save successful: [ファイル名]` … CSV 書き込み完了。

ログは `core_log` の設定に従い（例: `hc_csv.log`）出力先を確認すること。
