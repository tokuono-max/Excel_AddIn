# 重複チェック調査：左上コーナー選択時の Selection（VBA）

**目的**: 左上コーナー（行見出し×列見出しの交点）で全シート選択したとき、Excel が **Selection** にどのような範囲・行数・列数を返すかを、**本番の Python なしで**記録する。

**同梱ファイル**: `tools/excel_selection_inspect.bas`（マクロ `InspectSelectionAfterCorner`）

---

## 準備

1. **Excel** で調査用ブックを開く（CSV 取込済みの `Book1` でも、新規でも可）。
2. **開発**タブを表示（ファイル → オプション → リボンのユーザー設定 → 開発）。
3. **Alt + F11** で VBE を開く。
4. **ファイル → ファイルのインポート** で `tools/excel_selection_inspect.bas` を選ぶ。  
   または、同ファイルの中身を **標準モジュール** にそのまま貼り付け。

---

## 確認手順（共通）

各パターンで **次の順序を守る**ことが重要です。

1. 対象シートをアクティブにする。
2. **先に Excel 上で選択操作**（コーナー・列見出し・A1 など）を行う。
3. **すぐに** マクロ `InspectSelectionAfterCorner` を実行する。  
   - VBE でカーソルを `Sub` 内に置き **F5**、または  
   - 開発タブ → **挿入** → ボタン（フォームコントロール）→ マクロに `InspectSelectionAfterCorner` を割り当て。

4. 表示された **メッセージボックス**の内容をコピー（またはスクリーンショット）で残す。
5. 同じ内容が **`%TEMP%\excel_selection_inspect.txt`** に追記されるので、メモ帳で開いて比較してもよい。

---

## パターン一覧（すべて実行して比較）

| # | 操作（選択の直後にマクロ実行） | 本番で想定している意味 |
|---|-------------------------------|------------------------|
| A | **左上コーナー**（グレーの小さな四角）をクリック | シート全体選択 |
| B | **列見出し**をクリック（1 列まるごと） | 列全体（ログで `sel_c=1` になっていたパターン） |
| C | **セル A1** をクリック（1 セルのみ） | 単一セル |
| D | （任意）**Ctrl+A** を 1 回・2 回（環境によって Used 全体→シート全体の切替がある） | キーボード全選択 |

各パターンで、特に次の行を比較します。

- `Selection.Rows.Count` / `Selection.Columns.Count`
- `Selection.CountLarge`（エラーなら `Selection.Count` の行）
- `Intersect(Selection, UsedRange)` が **Nothing かどうか**

---

## 結果の読み方（本番ロジックとの対応）

- **A で** `Rows`・`Columns` がシート最大に近く、`CountLarge` が `Cells.CountLarge` に近い → 全シート相当として扱える材料。
- **B で** `Rows.Count = 1048576` かつ `Columns.Count = 1` → 「全シート」ではなく **1 列全選択**（本番ログのモード A と一致しやすい）。
- **Intersect が Nothing** → Python 側で `selection_rects` が空になり得る（別シート／極端な選択／タイミングなども要確認）。

---

## トラブルシュート

- **マクロが実行できない**: マクロの設定を「通知付きで無効」以下に変更し、ブックを信頼できる場所に置く。
- **`Count` でオーバーフロー**: 想定どおり。`CountLarge` の行を見る（マクロは `On Error Resume Next` で吸収）。
- **本番だけ失敗する**: VBA では成功するが Ribbon 経由の Python だけ失敗する場合は、**プロセス／スレッド／タイミング**の差を疑う（別ドキュメントの「VBA で選択を文字列渡し」などの根本策）。
