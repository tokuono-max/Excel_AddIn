# データ集約：シナリオ編集の「加工」「整形（DSL）」

セル座標から取得では、**主キー**と**連携キー**に **正規化・置換（正規表現）の入力欄はありません**。文字列の加工は **加工（チェック）** と **整形（DSL）** で行います。

---

## 主キー（セル座標ブロック）

1. **加工（チェック）** … トリム・全角→半角・日付など、オンにしたものだけ順に適用  
2. **整形（DSL）** … `ui_scenario_source_v1` の **`value_shape_script`**

旧シナリオ JSON に `normalize` / `replace_cell` が残っていても、**抽出エンジンでは使いません**。

---

## 連携キー（各定義行）

1. セルまたは固定値を取得  
2. **加工（チェック）** … 主キーと同趣旨  
3. **整形（DSL）** … `link_defs[]` の **`value_shape_script`**

旧 `normalize` / `replace` も **無視**します。固定値モードでも、入力した文字列に対して同じ **加工 → 整形** を適用します。

---

## 結合キー（各定義行）

1. セル座標から値を取得  
2. **加工（チェック）** … 連携キーと同趣旨（`join_defs[]` の **`checks`**）  
3. **整形（DSL）** … `join_defs[]` の **`value_shape_script`**

固定値モードはありません（セル座標のみ）。抽出は連携キーと同じ `postprocess_link_rule_value` を通します。

---

## 名前から取得

フォルダ名／ファイル名からの抽出のあと、**正規表現・置換**（`pattern` / `replacement`）→ **加工** → **整形** の順です（ここは従来どおり `extract_from_name` 内の `re.sub` あり）。

---

## 整形 DSL（共通）

- **実装:** `core.core_value_shape`
- **トークン区切り（先頭レベル）:** カンマ `,` またはセミコロン `;`（`tokenize_shape_script`。クォート内は区切りにしない）
- **クォート:** CSV 方式（内側の `"` は `""`）
- **`rep`:** 部分文字列の **すべて** を置換（先頭 N 回のみのモードはない）
- **`mid` / `cut` / `ins`:** 位置は **1 始まり**

**コマンド一覧・引数・記述例・検証エラー**の詳細は [データ集約_整形DSL_コマンドリファレンス.md](データ集約_整形DSL_コマンドリファレンス.md) を参照（本書と重複させない）。
