# svc_hd_nr 機能仕様書（行整形・ヘッダブロック横結合）

**対象**: 行整形（選択行をヘッダブロックとし、行を横列に結合してデータ領域を整形）  
**作成日**: 2026-03-09  
**目的**: 機能概要・用語・共通事項・整形ロジック・画面遷移を定義する。

---

## 1. 機能概要

Excel アクティブシートの**行もしくはセル行で選択された複数行**を順番に横列に結合し、後に続くデータ領域も同様に配置変更し整形する機能である。

---

## 2. 語句定義

| 用語 | 定義 |
|------|------|
| **アクティブシート** | 機能起動時点の Excel アクティブシートとする |
| **ヘッダブロック** | Excel アクティブシートの選択された行をヘッダブロックとする |
| **データ領域** | ヘッダブロックの次の行から、有効な最終行までを示す |
| **ヘッダ最大列** | ヘッダブロックの有効な（中間の空欄を許容する）右側最大列 |
| **データ結合** | データ領域からヘッダブロックの行数分をヘッダ最大列で切取り、順番に右側へ結合すること |

---

## 3. 共通事項

| 項目 | 内容 |
|------|------|
| Excel 操作 | リボンから呼ばれた時は Excel 操作を無効とする。Excel へ戻るとき操作を有効とする |
| 画面設定 | 機能画面およびサブ画面のすべての画面設定は JSON で定義し、Excel の前面表示および Excel の中央表示とする |
| 進捗 | 整形中は「整形数/総数」で進捗画面を表示する |
| ログ | 処理の起点毎にログへ出力。シート名、ヘッダブロック範囲、データ領域行、整形データ行、各画面表示 等を出力する |

---

## 4. 整形機能（処理フロー）

1. **複数行未選択** → ★ワーニング表示で注意を促す。確認後 Excel に戻る。
2. **複数行選択済** → ★ヘッダ確認画面を表示。ボタンは「開始」と「キャンセル」を配置。
3. **「キャンセル」選択** → Excel へ戻る。
4. **「開始」選択** → 以下を実行。
5. **ヘッダブロックの整形**  
   選択されたヘッダブロックの有効な（中間の空欄を許容する）右側最大列（ヘッダ最大列）で切取り、順番に右側へ結合しヘッダとする。
6. **結合したヘッダ**をヘッダブロックの先頭行へ設定する。
7. **データ領域**を、ヘッダブロックの次の行からとする。実装では**データ領域を一括読込**し、メモリ上でチャンクごとに横結合して出力 2 次元リストを構築する（高速化のため COM 往復を削減）。
8. **データ結合されたデータ**を、`core_xlc.write_chunk` でヘッダ行の次から**一括書込**する。
9. データ領域の最後まで、メモリ内で同様のチャンク結合を繰り返し、全出力行をまとめてから一括書込を行う。
10. **データ領域全てを整形完了**したら ★完了通知を表示し、OK 選択で Excel へ戻る。
11. **不足データが発生した場合**、不足データ値で結合を行い次の行へ設定する。
12. **不足行にスクロール移動**し、かつ行のハイライト表示をする。
13. ★**データ不足通知画面**を表示する（表示内容：不足発生行、不足行）。
14. データ不足通知確認後、該当の行選択をし Excel へ戻る。

---

## 5. UI の種類および画面遷移

| 画面 | 表示タイミング | 閉じ方 |
|------|----------------|--------|
| ワーニング | 複数行が選択されていない場合 | OK で Excel に戻る |
| ヘッダ確認 | 複数行選択済。開始/キャンセル | キャンセル→Excel。開始→整形開始 |
| 進捗画面 | 整形処理中（整形数/総数） | 処理完了後に閉じる |
| 完了通知 | 整形完了時 | OK で Excel に戻る |
| データ不足通知 | 不足データ発生時（該当行へスクロール・ハイライト後） | 確認後 Excel に戻る |
