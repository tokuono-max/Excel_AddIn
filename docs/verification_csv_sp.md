# CSVファイル分割 (csv_sp) 動作確認手順

**対象**: `svc_csv_sp` + `ui_qt.ui_csv_sp`（新方式）  
**確認日**: 2026-03-05

---

## 1. 事前準備

| 項目 | 内容 |
|------|------|
| Excel | アドイン読み込み済みの Excel を起動する。 |
| シート | アクティブブックに、**2行以上・1列以上**のデータがあるシート（1行目＝ヘッダ、2行目以降＝データ）。 |
| 設定ファイル | `config/ui_csv_sp.json` が存在し、MAIN / WINDOW が定義されていること。 |
| UI サーバ | 初回実行時に自動起動する。手動起動は不要。 |

---

## 2. 呼び出し経路の確認

- **VBA / リボン**: 「ファイル分割」などから `CallSplitFile` → `Main.RunPythonSafe("split_csv", sId)` が呼ばれる。
- **hc_main**: `split_csv(target_hwnd, sheet_id)` → `_call_svc_server(ACTION_CSV_SP, book_ptr, sheet_id)` で svc_server に委譲。
- **svc_server**: `svc.svc_csv_sp.split_csv(book, sheet_id)` を実行。
- **svc_csv_sp**: キー列・出力先を UI サーバへ依頼（IPC）→ 結果受信後に同一プロセス内で分割実行（進捗画面はなし）。

## 4. 処理フロー（参考）

1. **設定ダイアログ**: UI サーバが `ui_csv_sp.create_dialog(req_dict, parent_hwnd, sheet_id)` で `_SplitDialog` を生成。キー列一覧（ヘッダ）・出力先フォルダを表示。
2. **結果の受け渡し**: ユーザーが「分割実行」を押すと、`status=OK`, `key_idx`, `output_dir` が result_path の pickle に書き込まれる。
3. **分割実行**: `svc_csv_sp._watch_result_sp` が result_path を検知し、シートの used_range を読み、キー列でグループ化して出力先に CSV を出力。進捗画面は表示しない（同期的に実行）。
4. **通知**: `core_stat.set_status_info` でステータスバーに完了メッセージを表示。

## 5. 動作確認

### 事前（Python のみ）

- プロジェクトルートで次を実行し、即終了・例外なしで OK が表示されればエントリ・インポートは問題なし。
  ```powershell
  cd c:\Project\Python\Excel_AddIn
  .venv\Scripts\python.exe -c "from svc import svc_csv_sp; svc_csv_sp.split_csv(None, ''); print('OK')"
  ```
  - `book is None` のため早期 return し、ダイアログは出さない。

### 本番（Excel から）

1. **Excel でアドインを有効にし、ブックを開く。**
2. **2行以上・複数列のデータがあるシートをアクティブにする。**
3. **リボンから「ファイル分割」を実行。**
4. **確認項目**
   - 「ファイル分割設定」ダイアログが表示される（タイトルは config/ui_csv_sp.json の MAIN.TITLE）。
   - キー列を選択し、出力先フォルダを指定して「分割実行」→ 出力先にキー値ごとの CSV が作成される。
   - ステータスバーに「ファイル分割が正常に完了しました。｜基準: … ｜ 生成: N ファイル ｜ 出力先: …」と表示される。
   - キャンセル時: 「キャンセル」→ 何も出力されず終了。
5. **ログ**: 不具合時は `core_log` の設定先（例: hc_csv.log）および `[CSV_SP]` のログを確認。
