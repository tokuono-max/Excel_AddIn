# *_hd_in / *_hd_nr / *_undo 運用ログ Plan

**目的**: 運用に必要なログの一覧を Plan として定義する。モジュール実装時の参照用。

---

## 1. svc_hd_in（ヘッダ挿入）運用ログ一覧

| 種別 | ログ内容 |
|------|----------|
| 開始 | `[HD_IN] 開始 sheet_id=%s` |
| 完了 | `[HD_IN]` （定型文で完了） |
| エラー | 対象ブックなし, 対象シートなし sheet_id=%s, book.app なし, 致命的エラー |

---

## 2. svc_hd_nr（行整形）運用ログ一覧

| 種別 | ログ内容 |
|------|----------|
| 開始 | `[HD_NR] 開始 sheet_id=%s シート=%s` |
| 完了 | `[HD_NR] 完了 シート=%s ブロック数=%s 不足行数=%s` |
| ユーザー操作 | 複数行未選択, ユーザーキャンセル |
| エラー | 対象シートなし, 読込失敗, 書込失敗, UI 失敗等 |

---

## 3. svc_undo（元に戻す）運用ログ一覧

| 種別 | ログ内容 |
|------|----------|
| スナップショット | `[UNDO] スナップショット保存 開始/完了` book=%s sheet_id=%s, key=%s 行数=%s |
| 復元 | `[UNDO] 復元 開始/完了` book=%s sheet_id=%s, シート=%s |
| エラー | キャッシュなし, 構造復元モジュールなし, 各種 warning/exception（既存維持） |

---

## 4. svc_dt_hm / svc_dt_ymd（日付・時刻変換 / 日付変換）運用ログ一覧

| 種別 | ログ内容 |
|------|----------|
| 開始 | `[DT_HM] 開始` / `[DT_YMD] 開始`（既存維持） |
| 完了 | `[DT_HM] 運用ログ 日付・時刻変換 走査=%s 変換件数=%s` / `[DT_YMD] 運用ログ 日付変換 走査=%s 変換件数=%s` |
| ワーニング | `[DT_HM] 運用ログ 日付形式なし 走査=%s 非日付セルのみ` / `[DT_YMD] 運用ログ 日付形式なし 走査=%s 非日付セルのみ` |
| エラー | 読込失敗, 選択範囲なし, 例外（既存維持） |

---

## 5. svc_trm_ex（文頭・文末トリム）運用ログ一覧

| 種別 | ログ内容 |
|------|----------|
| 開始 | `[TRM_EX] 開始` |
| 走査 | `[TRM_EX] 走査 選択範囲 rows=%s cols=%s 文頭=%s 文末=%s` |
| 削除対象なし | `[TRM_EX] 削除対象なし` |
| ユーザーキャンセル | `[TRM_EX] ユーザーキャンセル` |
| 完了 | `[TRM_EX] 運用ログ トリム 種別=%s 削除文頭=%s 削除文末=%s` |
| エラー | 有効データ領域なし（used_range 0 行/0 列）, 読込失敗, 書込失敗, save_undo_snapshot 失敗, 例外（既存維持） |

---

## 6. svc_help（操作マニュアル表示）運用ログ一覧

| 種別 | ログ内容 |
|------|----------|
| 開始 | `[HELP] 開始` |
| ファイル未存在 | `[HELP] Info.txt not found: %s` |
| 表示依頼 | help UI request: %s（req_path） |
| 完了 | `[HELP] 運用ログ ヘルプ表示 閉じるまで待機完了` |
| エラー | core_xlc なし, Excel コンテキストなし, help UI request 失敗, 例外（既存維持） |
