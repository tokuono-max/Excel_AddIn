# svc_csv_ld 機能仕様書（CSV読込）

**対象**: CSV読込（ファイル選択 → Excel シートへの読込・出力）  
**作成日**: 2026-03-06  
**目的**: 機能概要・UI・画面遷移・ログを一括で定義し、実装の正本とする。

---

## 1. 機能概要

ユーザーが選択した **CSV ファイル** を読み込み、**Excel アクティブブック** のシート（GUID 紐付け済みの対象シートを起点）に出力する機能である。

- **入力**: ユーザーがファイル選択ダイアログで指定した CSV ファイルのパス
- **出力**: Excel シートへのデータ書込。行数が一定数を超える場合は複数シートに分割して書込。書込後に列幅のオートフィットを実行。

---

## 2. 前提条件

| 項目 | 内容 |
|------|------|
| **対象ブック** | 機能起動時点の Excel アクティブブック |
| **対象シート** | GUID で紐付けられたシート（起点）。空の場合はそのシートに書込；既にデータがある場合は新規シートを追加して書込 |
| **CSV ファイル** | ユーザーがファイル選択ダイアログで 1 件選択。キャンセル時は処理を行わない |

---

## 3. ファイル読込・書込

| 項目 | 内容 |
|------|------|
| **文字コード** | 自動検出（バイナリ／BOM 等を利用）。検出結果に従って読込 |
| **書込先** | 1 行目はヘッダとして書込。分割時は各シートの先頭にヘッダを付与 |
| **行数制限** | 1 シートあたりの最大行数（MAX_ROWS_PER_SHEET）を超える場合は複数シートに分割して書込 |
| **分割時のシート名** | ベース名が既存と重複しないよう解決したうえで、`ベース名-1`, `ベース名-2`, … とする |

---

## 4. 画面遷移・UI

| 項目 | 内容 |
|------|------|
| **UI 種類** | ファイル選択ダイアログ、分割確認メッセージ（条件付き）、進捗画面、完了通知（ステータスバー等） |
| **画面遷移** | Excel リボン → **ファイル選択ダイアログ** → （行数超過時のみ **分割確認**）→ **進捗画面** → 完了 → Excel |

### 4.1 各 UI の挙動

| UI | 開くタイミング | 閉じるタイミング |
|----|----------------|------------------|
| **ファイル選択** | リボン「CSV読込」で開く | 「開く」または「キャンセル」で閉じる。表示中は Excel 操作を無効化し、閉じたあと有効に戻す |
| **分割確認** | ファイル行数が MAX_ROWS_PER_SHEET を超えるときのみ表示（Win32 MessageBox） | 「はい」で続行、「いいえ」で処理中止 |
| **進捗画面** | ファイル選択で「開く」を押したあと、進捗用リクエスト投入から一定時間待機してから表示 | 工程 4（完了）表示後、所定秒数経過で自動で閉じる |
| **完了通知** | 進捗が完了したあと | ステータスバー／HC_NOTIFY_RETV で「CSV読込終了｜…」を表示。ポップアップは VBA 側で制御 |

### 4.2 進捗の工程

| 工程 | 表示内容 |
|------|----------|
| 1/4 | ファイル解析中（0%） |
| 2/4 | Excelへ書き込み中（done/total と pct で更新） |
| 3/4 | 列幅調整中（99% 維持） |
| 4/4 | 完了（100%）→ 所定秒数表示後に閉じる |

---

## 5. UI 表示の共通仕様

| 項目 | 内容 |
|------|------|
| **Excel 操作** | ファイル選択・進捗表示中は Excel 操作を無効とする場合あり。閉じたあとは有効に戻す |
| **表示位置** | 進捗画面は Excel ウィンドウの中央に表示（config で CENTER_ON_EXCEL 等を指定） |
| **前面表示** | 常に Excel の前面に表示（Excel と親子関係）。他アプリのウィンドウが前面の場合は後ろに隠れる（TOPMOST は false 推奨） |

---

## 6. 設定・config

| 項目 | 内容 |
|------|------|
| **設定ファイル** | `config/ui_csv_ld.json` |
| **読込タイミング** | 機能起動時（各画面表示時に create_dialog 等経由で読込）。core_cst がファイル mtime でキャッシュ |
| **主な項目** | MAIN.TITLE（ファイル選択ダイアログのタイトル）、MAIN.FILTER（ファイル種別フィルタ）、SCREENS.PROGRESS（進捗画面の TITLE / WINDOW 等） |

---

## 7. ログ出力

| 項目 | 内容 |
|------|------|
| **使用モジュール** | `core.core_log`（`get_logger`） |
| **内容** | 処理開始・ファイル選択結果・進捗 phase の書き込み・読込／書込の進捗・オートフィット・完了など |
| **フォーマット** | 既存のログ出力に合わせる（時刻・レベル・モジュール名・メッセージ）。出力先は core_log の既定（例: hc_csv.log）に従う |

---

## 8. ファイル名・パス（日本語等）

| 項目 | 内容 |
|------|------|
| **日本語・Unicode** | Windows および本アドインでは、**ファイル名・フォルダパスに日本語（Unicode）を使用できる**。読込元 CSV のパス・保存先パスに日本語を含めてよい |
| **注意** | 一部のレガシー環境や他ツールでは Unicode パスで問題が出る場合がある。その場合は英数字のパスを利用すること |
