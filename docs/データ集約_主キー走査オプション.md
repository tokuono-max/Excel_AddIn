# データ集約：主キー走査オプション（セル座標）

シナリオ編集の **主キー**（セル座標から取得）まわりで、走査対象行を制御するオプションです。  
本番一括・マスタ／シナリオデバッグとも **`svc/svc_data_agg_extract.py` の同一経路**で効きます。

文言・既定値の UI 正本は `config/ui_data_agg.json` の `SCREENS.SCENARIO_EDIT.DETAIL_CELL` です。

---

## 1. 非表示・フィルタ行を除く（`skip_hidden_rows`）

| 項目 | 内容 |
|------|------|
| UI ラベル | 非表示・フィルタ行を除く |
| JSON | 取得ソース直下 `skip_hidden_rows`（boolean） |
| 既定 | **OFF**（未設定も OFF） |

### 動作

| 設定 | 動作 |
|------|------|
| **OFF（既定）** | 行の表示／非表示に関わらず **全行** を主キー走査する |
| **ON** | Excel 上で **見えている行だけ** を主キー走査する（非表示行は件数に含めない） |

### 「見えている」の意味

- 対象は **ファイルに保存された行の非表示フラグ**（`hidden`）です。  
  Excel でフィルタや非表示を変えても、**保存前**の状態は抽出に反映されません。
- 除外される典型例:
  - **手動非表示**（行を選んで「非表示」）
  - **オートフィルタ**で条件外となり隠れた行
  - （同じ仕組みで）グループ化の折りたたみなどで `hidden` が付いた行
- **列の非表示は対象外**（行の可視のみ）。

### 対象形式

- 有効: `.xls` / `.xlsx` / `.xlsm`
- 無効: **CSV**（フラグがあっても無視）

### 連携・結合との関係

非表示行を飛ばすと、主キーの並びと Excel 上の行オフセットがずれることがあります。  
抽出は **`rule_iter_index`（シート上の元オフセット）** を残し、連携キー・結合キーは同じ Excel 行を参照します。

### 実装メモ

- 判定: `svc/data_agg_row_visibility.py`
- ON 時のみ、非表示情報の読取が増えます（抽出全体に対しおおむね数％〜数十％程度の目安）。

## 2. 主キーをスキップ（`skip_empty_primary`）

| 項目 | 内容 |
|------|------|
| UI ラベル | 主キーをスキップ |
| JSON | `skip_empty_primary` / 照合文字列 `skip_primary_match` |
| 既定 | OFF |

主キー値が空（または `skip_primary_match` で指定した値）の行を **結果から除く**（圧縮）します。  
終了条件（空白まで／N件／終端）のあとに効くイメージで、**非表示除外（§1）の後**に適用されます。

照合例（ツールチップ準拠）:

- 空欄のみ → 入力を空のまま
- 空欄と文字 → `,A,-` のようにカンマ区切り
- 文字のみ → `A,-`

---

## 3. スキップ行を前置に使う（`skip_carry_seed`）

| 項目 | 内容 |
|------|------|
| UI ラベル | スキップ行を前置に使う |
| JSON | `skip_carry_seed` |
| 既定 | OFF |
| 前提 | **主キーをスキップが ON** のときだけ有効（OFF 時は UI も無効） |

主キースキップ行の **連携値**（連携側の「空欄は前回値を保持」ON の項目）を、次行以降の前置の種にします。  
空の連携値では種を上書きしません。

**注意:** §1 で非表示にした行はそもそも走査されないため、その行の値は前置の種になりません。

---

## 4. 連携：空欄は前回値を保持（`carry_empty`）

連携キー定義ごとのオプション（`link_defs[].carry_empty`）。  
同じシート内で、空欄の連携値に直前の非空値を入れます。シート／ファイルが変わるとリセットします。

デバッグ結果一覧では、前置保持対象の項目名の文頭に **`・`** を付けて表示します（本番一括の見出しには付けません）。

---

## 5. 処理順（セル主キー）

1. 終了区分に沿ってセルを辿る  
2. **`skip_hidden_rows` ON** → 非表示行を飛ばす（`rule_iter_index` を記録）  
3. **`skip_empty_primary` ON** → 空／照合一致の主キー行を結果から除く（必要なら `skip_carry_seed`）  
4. 連携・結合は `rule_iter_index`（無ければ `iter_index`）で同じ Excel 段を参照  
5. 連携の `carry_empty` で空欄を前置補完
