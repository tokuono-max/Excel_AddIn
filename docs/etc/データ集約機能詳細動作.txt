１．データ集約機能基本動作
	１．１語句
		初期フォルダ	：ファイルやフォルダダイヤログで最初に表示させるフォルダ
		基準フォルダ	：データ集約する対象のトップフォルダ
		列の集合体		：１シナリオで収集したデータの塊、標準で「値・ファイル名・フルパス」で、設定により値１・値２...となるケースが存在する
						：レコード作成時は値だけの結合で、ファイル名やフルパスは「名前から取得」設定時の照合用キーに使われる
		マスタ項目		：データ集約結果の項目名を指す
		データ集約対象ファイル：フルパスでデータ集約から渡される対象ファイル一覧
		
	１．２前提
		今のところなし
		
	１．３全体動作
		○初期フォルダは、last_folder.txtに記載のフォルダを採用し、変更した場合はlast_folder.txtを更新する
		○すべての表示およびボタンは、JSONファイルでツールチップを設定する
		○シナリオに基づいたデータを取集し、結合後Excelシートに書き込む
		○シナリオはシナリオ編集機能により作成する
		○データ収集はシナリオ単位で列データをして取得する
		○シナリオで収集されるデータは値の他、収集元のフルパスおよびファイル名ならびに設定により結合キーの値と結合項目が一緒に収集され、列の集合体が内部的に作成される
		○登録されているすべてのシナリオの列集合体が作成した後、先頭のマスタ項目名から順に結合キーか結合パスでレコードを形成させる
	
２．データ集約UI
	マスタ項目読込やタブ１でマスタ項目表示・マスタ項目ごとのシナリオ編集の入り口・シナリオ要約表示の他、タブ２でフォルダ指定及び対象ファイル表示を行う
	また、制御系とし、シナリオ保存・シナリオ読込・シナリオ実行・ステップ実行・キャンセル ボタンを設けている
	２．１項目読込
		マスタ項目をとこから読み込むか指定する
		アクティブシート１行目	：アクティブシートの１行目に表示されている項目を読込み、項目一覧へ表示する
		CSVファイル				：ファイルダイヤログで選択したCSVファイルの１行目の項目を読込み、項目一覧表へ表示する
	
	２．２項目・シナリオ（タグ１）
		読込んだマスタ項目を縦に一覧表示し、右側にシナリオ編集ボタンと、さらに右側に設定されているシナリオ要約を表示する
		リストは互い違いに背景色（薄いベージュ色）を付ける
		項目名		：読込んだマスタ項目名を表示
		シナリオ編集：マスタ項目名ごとのシナリオ編集画面に移行する。 また、シナリオ編集画面に移行時、タグ２で設定した条件でファイル検索を行い、そのファイル一覧をシナリオ編集へ渡す（タグ２の検索ボタンと同じ動作）
		シナリオ要約：マスタ項目名ごとに設定されているシナリオの要約を表示する
		
	２．３フォルダ・ファイル指定（タグ２）
		処理対象のフォルダとサブフォルダ有無を含むかを指定する。 補助的に拡張子指定を入れている
		検索ファイル一覧は、互い違い行で背景色（薄いベージュ色）を付ける
		フォルダ選択ボタン	：データ集約対象のフォルダを選択し、基準フォルダに表示させる
		サブフォルダ含む	：基準フォルダ配下のサブフォルダも対象に入れるか否かをチェックボックスでチェックする
		拡張子		：対象ファイルの拡張子をチャックボックスでチェックする
						.xls	：Excelファイルを対象とする
						.xlsx	：Excelファイルを対象とする
						.CSV	：CSVファイルを対象とする
		検索ボタン	：検索選択でフォルダ条件で対象ファイルをフルパスで取得し一覧表示する

	２．４ボタン関係
		以下のボタンを配置する
		シナリオ読込		：保存済みのシナリオファイルを読込、項目一覧・シナリオ、各シナリオ、フォルダ設定に展開する
		シナリオ保存		：マスタ項目、各マスタ項目に設定しているシナリオ、対象フォルダの設定をシナリオファイルとして任意の名前で保存する
		ステップ実行		：マスタ項目単位でステップ実行を行う。詳細は
		一括実行			：シナリオを一括で実行し、アクティブシートへ出力する。 詳細は４．ステップ実行参照
		キャンセル			：Excelへ戻る

３．シナリオ編集
	３．１セル座標から取得
		種別で「セル座標から取得」を選択した時のシナリオパラメータ設定を以下に示す
		識別：マスタ項目名_シナリオ番号 で自動採番され、エラーイベント出力時の識別名として使用
		
		３．１．１シナリオ一覧
			登録されているシナリオとシナリオの要約を表示する（字切れあり） また、ツールチップに要約を表示する
			選択されているシナリオの要約を表示する
			追加・複製・削除 ボタンで、シナリオの追加・複製・削除が行える
			▲・▼ ボタンで、一覧の縦順（取得ソースの評価順）を入れ替える。複数ソースがある場合、上から順に extract が走査する順序と一致する
			ステック実行で、選択したシナリオの設定が期待通りかを確認するステップ実行を設ける。詳細は４．ステップ実行参照
			
		３．１．２ファイルフィルタ
			データ集約ファイルから、対象ファイルを絞る
			ファイル名判定：	コンボボックスで 完全一致／含む／含まない を選択する（ファイル名入力より上に配置）
			ファイル名：	ファイル名判定に従い対象を絞る文字列。空欄の場合すべてのファイルが対象
			ファイル拡張子：対象のファイルの種類を選択する。
			
		３．１．３シート名
			Excelブックであれば、対象のシートの設定、CSVファイルであれば、シート概念がないため本設定は無効
			シート名判定：以下の通り
							左端シート	：ブックの左端に表示されるシートを指す
							完全一致	：入力文字と完全一致
							含む		：入力文字が含まれる
							含まない	：入力文字が含まれない
			シート名	：入力文字
			
		３．１．４値取得
			対象のシートから値を取得する位置（座標）や、移動オフセット・終了条件などを設定する
			Excelブックの場合、対象シートが複数存在する場合、シート間のフォーマットは同じと言う前提で値の取得を繰り返す
			行/列移動オフセットが0/0であった場合、値は１シートもしくは１ファイル単位で１個の値取得と解釈する
			セル座標		：Excelセル座標指定方式で、取得する値の座標を文字列で入力（英字＋数字のパターンでなければ入力時エラー通知する）
			行移動オフセット：次の値までの移動セル数を入力する （0設定の場合、移動は行わない）
			列移動オフセット：次の値までの移動セル数を入力する （0設定の場合、移動は行わない）
			終了区分		：以下の通り
								空白まで	：空欄検出で終了し、設定により次のシート/次のファイル/次のシナリオに移行する
								N件			：指定された件数を取得後、設定により次のシート/次のファイル/次のシナリオに移行する
			加工			：以下の通り
								トリム	：先頭/文末の空欄を削除する
								全角→半角：全角を半角に変換する
								日付変換(yyyy/mm/dd)：日付形式のデータをyyyy/mm/dd形式の文字列に整形する
			整形（DSL）	：ui_scenario_source_v1 の value_shape_script。「加工」の後に左から順に適用。主キーに正規表現・置換欄はない（旧 JSON の normalize 等は抽出で無視）。実装は core.core_value_shape。先頭レベルのトークン区切りはカンマまたはセミコロン（クォート内は除く。詳細は docs/データ集約_整形DSL_コマンドリファレンス.md）
			
		３．１．５連携キー
			値取得と連携して取得する値の位置を指定する
			行/列移動オフセットは、値取得の設定と同じとし、書込みモード、終了区切りはなどは値取得に依存する
			未設定時、連携する値はない
			連携キーの連携項目に選択されたマスタ項目名は、シナリオ登録およびシナリオ実行はスキップされ、データ集約画面の項目・シナリオに表示される該当行はグレイアウトし選択できないようにする
			セル座標		：Excelセル座標指定方式で、連携する値の座標を文字列で入力（英字＋数字のパターンでなければ入力時エラー通知する）
			連携項目		：取得する値と比較するマスタ項目名を選択する（都度マスタ項目名を選択リストに表示する必要がある）
			加工			：以下の通り
								トリム	：先頭/文末の空欄を削除する
								全角→半角：全角を半角に変換する
								日付変換(yyyy/mm/dd)：日付形式のデータをyyyy/mm/dd形式の文字列に整形する
			整形（DSL）	：link_defs の value_shape_script。加工の後に適用。正規表現・置換欄はない（旧 JSON は無視）。固定値モード時も同一の加工・整形を適用
			＋連携キー追加	：連携キーを増やす場合に使用するボタンであり、ボタンを選択する都度連携キー定義＃Nブロックが追加される

		３．１．６結合キー
			マスタ項目との関連性を設定する。 結合キーは複数設定でき全てAND条件となる
			セル座標		：Excelセル座標指定方式で、取得する値の座標を文字列で入力（英字＋数字のパターンでなければ入力時エラー通知する）
			行移動オフセット：次の値までの移動セル数を入力する （0設定の場合、移動は行わない）
			列移動オフセット：次の値までの移動セル数を入力する （0設定の場合、移動は行わない）
			結合項目		：取得する値と比較するマスタ項目名を選択する（都度マスタ項目名を選択リストに表示する必要がある）
			（画面に加工・整形欄はない。抽出は連携と同じ後処理関数を通すが join_defs に checks / value_shape_script が無ければ実質セル値そのまま）
			＋結合キー追加	：結合キーを増やす場合に使用するボタンであり、ボタンを選択する都度結合キー定義＃Nブロックが追加される

	３．２名前から取得
		種別で「名前から取得」を選択した時のシナリオパラメータ設定を以下に示す
		目的（確定）：セル座標等で既に集約済みのマスタ行を前提とし、当該行の不足データをフォルダ名またはファイル名（パス）から補う。新規行の追加をシナリオ書込みモードで行うことは想定しない。
		識別：マスタ項目名_シナリオ番号 で自動採番され、エラーイベント出力時の識別名として使用
		
		３．１検索条件
			対象となるフォルダ名およびファイル名の条件を設定する
			検索対象		：フォルダ名/ファイル名の選択、文字列を抽出する対象が、フォルダ名かファイル名かを指定する
			検索条件		：以下の通り
								先頭		：検索文字列が先頭にあるフォルダ名およびファイル名を対象とする
								含む		：検索文字列が含まれるフォルダ名およびファイル名を対象とする
								含まない	：検索文字列が含まれないフォルダ名およびファイル名を対象とする
			検索文字列		：検索する文字列を入力 （フォルダ名およびファイル名禁止文字が入力された場合エラーを表示）
			
		３．２文字列抽出条件
			フォルダ名およびファイル名から抽出する文字列の条件を設定する
			抽出タイプ		：以下の通り
								検索文字				：検索条件で入力した検索文字の先頭位置から開始
								位置					：文字位置から開始
								区切り文字（デリミタ）	：指定される区切り文字で抽出する
			デリミタ入力	：デリミタ記号を入力		：抽出タイプで「区切り文字」が選択された時イネーブル、デフォルト"_"
			抽出ブロック	：何ブロック目を抽出するか入力：区切り文字を除いたブロック文字列を抽出し、ブロックオーバーの場合空欄とする
														：抽出タイプで「区切り文字」が選択された時イネーブル
			開始位置		：開始の文字位置を入力		：抽出タイプで「位置」が選択された時イネーブル
			終了位置		：以下の通り
								最後まで	：最後までを指定
								文字数		：文字数指定で終了指定
								文字指定	：文字指定で終了指定
			抽出長さ/値		：終了位置の選択により文字数/文字列入力となる （「終了位置」最後まで を選択時、ディセーブル）
			正規表現		：正規表現の入力 （空欄は何もしない）
			置換			：置換入力 （空欄は何もしない）
			加工			：以下の通り
								トリム	：先頭/文末の空欄を削除する
								全角→半角：全角を半角に変換する
								日付変換(yyyy/mm/dd)：日付形式のデータをyyyy/mm/dd形式の文字列に整形する
			整形（DSL）	：value_shape_script。画面上は「正規表現・置換」および「加工」の下に入力。抽出エンジンでは正規表現・置換（extract_from_name 内）の後、加工、最後に DSL を適用。仕様は３．１．４の整形（DSL）と同じ（core.core_value_shape、rep はすべて置換）
			書込みモード	：以下の2種のみ（行追加・複製追加は本ツールでは提供しない。理由は上記「目的」参照）
								空き上書き	：該当箇所が空欄の時だけ書込み、その他はスキップ
								強制上書き	：強制的に上書きする
								
		３．３連携キー（フルパスで結合）
			本設定の対象となっているフルパスと、連携項目に設定されたマスタ項目の列集合体の中のフルパス一致した箇所の本シナリオが登録されているマスタ項目位置に代入する
			連携項目		：マスタ項目を選択	（都度マスタ項目名を選択リストに表示する必要がある）

		３．４由来パス列・パス正規化・名前取得の行照合（実装・2026）
			由来パス列（結合パス項目）
				シナリオ JSON の items[].join_path_item_id で、正規化フルパスを書き込むマスタ列を items[].id または name で指定する。省略時は項目一覧の先頭列（主キー相当）
				シナリオ編集では種別行の下にコンボを置き、全マスタ項目 id から選択する（既定＝先頭列）
			パス正規化（比較・格納の共通ルール）
				内部では pathlib の resolve 相当で絶対パス化し、区切りは POSIX 形式（/）に統一する
				Windows ではパス文字列の比較を大文字小文字非区別とする（casefold）
				実装の単一入口は svc.data_agg_path_norm.normalize_source_path
			セル座標系でも由来パス列へ値を付与
				セル取得のみの項目でも、上記由来パス列に、走査中ファイルの正規化フルパスを主キー反復ごとに付与する（名前取得の path_item 指定時のフルパスと同一形式）
			名前から取得（name_extract のみの項目）の行への値の割当
				ファイル名モード（source_type=file_name）：内部の由来パス（正規化）が、当該走査ファイルの正規化フルパスと一致する行だけ、当該項目列へ抽出値を書く。一致しない行は空欄
				フォルダ名モード（source_type=dir_name）：由来パス（正規化）が、当該ファイルの親ディレクトリの正規化フルパス配下（同一パス含む）にある行すべてに、同一の抽出値を書く。反復 index をまたいで伝播する
				同一項目内でセル座標系と名前系を混在させない（JSON 検証エラーおよびシナリオ編集 UI で種別変更を拒否）

４．ステップ実行
	ステップ実行には、大きく分けて以下の２種類がある
		シナリオステップ実行	：指定された単一のシナリオで設定ステップごとに実行し、シナリオが期待通りか確認する際に使用（シナリオ編集画面で使用）
		データ集約ステップ実行	：マスタ項目ステップで実行し、データ集約全体で期待通りか確認する際に使用する（データ集約画面で使用）
		
		４．１シナリオステップ実行
			シナリオ編集画面のステップ実行が選択されたときに、選択されているシナリオをフェーズごとにステップ実行し、その過程の条件を表示しながら確認できる
