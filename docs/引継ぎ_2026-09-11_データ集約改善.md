## 1. 終了通知が出ない（ODN-164）

### 症状

- 特定シナリオ（行数大・Excel書込みが長い）だけ完了ダイアログが出ない
- 他シナリオ（例: ODN375）では出る

### 原因

1. 計算成功後に `data_agg_batch_compute` が `_finish_compute_only` 相当で **active pickle を早期削除**
2. UI の batch done ポーリングは active 消滅後の猶予が **15秒**
3. ODN-164 の書込みが約15秒超 → 猶予切れでポーリング停止 → `write_batch_done_notify` を読めない

### 修正（済み）

| ファイル | 内容 |
|----------|------|
| `svc/data_agg_batch_compute.py` | 書込み dispatch 成功後は active を消さない（書込み側 `_finish_write` で通知後にクリア） |
| `ui_qt/ui_data_agg.py` | active 消滅後の猶予 **15秒 → 300秒** |
| `tests/test_batch_done_poll_grace.py` | 上記の回帰テスト |

### 確認ポイント

- ODN-164（ローカル `C:\Project\データ集約テストファイル\ODN164`）で終了通知が出ること（ユーザー確認済み）
- 短いシナリオでも通知・二重通知がおかしくないこと

## 2. 所要時間 4:30 → 6:10（改善で遅くなったか）

### ログ根拠（`hc_csv.log` / `hc_csv_diag.log`、同一 ODN-164・15710行）

| 時刻 | compute_ms | 備考 |
|------|------------|------|
| 15:05 | ≈451s（7.5分） | 同日・同シナリオで遅い例 |
| 15:41 | ≈262s（4.4分） | ユーザー体感「4分30秒」に一致 |
| 17:35 | ≈358s（6.0分） | **通知修正の直前** |
| 18:09 | ≈358s（6.0分） | **通知修正の直後**＋書込みで約6分10秒 |

### 結論

- **終了通知修正は遅延要因ではない**（修正前後の compute がほぼ同一）
- **改善による恒常的な遅延とは断定しない**（同日 4.4分〜7.5分のばらつき）
- ODN-164 シナリオに `skip_hidden_rows`・日付加工は無く、#11（hidden フルオープン）／日付変換修正の影響はほぼ無し
