# docs/ 配置方針（改善 #19）

## 役割分担

| 種類 | 置き場 | git |
|------|--------|-----|
| 開発正本 | `docs/*.md`、`docs/agent_handoff_*.md` 等 | 追跡する |
| 社内提出用 Word | `docs/Ver<版>/` の `*.docx`（`*_A.docx` は提出確定版） | 追跡する |
| 印刷・配布用 PDF | `docs/PDF/*.pdf` | **生成物。追跡しない**（`.gitignore`） |
| 旧版アーカイブ | `docs/archive/Ver*` | 参照用。削除せず履歴として残す |

## 運用メモ

- `docs/PDF/` の名前に反し、インストール手順・概要の **docx 原紙**も同フォルダに置くことがある。docx は提出・編集用として残す。
- PDF は Word 等から再出力できる。リポジトリ容量を抑えるため PDF はコミットしない。
- 現行提出セットの正本フォルダは `docs/Ver1.1.12.8/`。前版 `Ver1.1.10.6` は同階層に残す（必要なら後で `docs/archive/` へ）。
- 生成スクリプト: `docs/_gen_v11128_docs.py`（前版は `_gen_v11106_docs.py`）。出力名と `*A.docx`（手修正後提出版）の関係に注意。
- 図の流用: `docs/_copy_figs_v11106_to_v11128.py` で `*_V11106A.docx` の同図番号画像を `*_V11128.docx` の【画像挿入】枠へコピーする。UI が大きく変わった枠（例: シナリオ編集の図3-4 主キー）はスキップし、新規キャプチャを推奨。

## やってはいけないこと

- 提出用 `*_V11128A.docx` / `*_V11106A.docx` の無断削除
- 確認前のインストール手順 A/B docx の片方削除
- 開発用 `.md` 正本の削除
