# docs/ 配置方針（改善 #19）

## 役割分担

| 種類 | 置き場 | git |
|------|--------|-----|
| 開発正本 | `docs/*.md`、`docs/agent_handoff_*.md` 等 | 追跡する |
| 社内提出用 Word | `docs/Ver<版>/` の `*.docx`（`*_A.docx` は提出確定版） | 追跡する |
| 印刷・配布用 PDF | `docs/PDF/*.pdf` | **生成物。追跡しない**（`.gitignore`） |
| 旧版アーカイブ | `docs/archive/Ver*` | 参照用。削除せず履歴として残す |

## 運用メモ

- `docs/PDF/` の名前に反し、インストール手順・概要の **docx 原紙**も同フォルダに置くことがある。docx は提出・編集用として残す。
- PDF は Word 等から再出力できる。リポジトリ容量を抑えるため PDF はコミットしない。
- 現行提出セットの正本フォルダは `docs/Ver1.1.10.6/`。旧 `Ver1.1.9.5` は `docs/archive/` へ移した。
- 生成スクリプト: `docs/_gen_v11106_docs.py` 等。出力名と `*A.docx`（手修正後提出版）の関係に注意。

## やってはいけないこと

- 提出用 `*_V11106A.docx` の無断削除
- 確認前のインストール手順 A/B docx の片方削除
- 開発用 `.md` 正本の削除
