# svc_csv_sv 機能仕様書（CSV保存）

**対象**: CSV保存（アクティブシートの内容を CSV ファイルとして保存）  
**作成日**: 2026-03-06  
**目的**: 機能概要・UI・画面遷移・ログを一括で定義し、実装の正本とする。

---

## 1. 機能概要

**Excel アクティブシート** の使用範囲を読み取り、ユーザーが指定したパスに **CSV ファイル** として保存する機能である。

- **入力**: 機能起動時点の Excel アクティブシート（または GUID で指定されたシート）、およびユーザーが保存先ダイアログで指定したファイルパス
- **出力**: 指定パスへの CSV ファイル書込（UTF-8 BOM）。保存後はステータスバー・通知で保存先・行数等を表示

---

## 2. 前提条件

| 項目 | 内容 |
|------|------|
| **対象シート** | 機能起動時点のアクティブシート。または GUID（sheet_id）で指定されたシート |
| **保存先** | ユーザーが「名前を付けて保存」ダイアログで指定。キャンセル時は保存処理を行わない |

---

## 3. ファイル保存

| 項目 | 内容 |
|------|------|
| **保存の流れ** | 保存先選択ダイアログでパスを指定 → 進捗画面表示 → シートデータ読込 → CSV 書込 → 完了通知 |
| **ファイルフォーマット** | **UTF-8（BOM）**、拡張子はユーザー指定（通常 `.csv`） |
| **内容** | シートの UsedRange をそのまま 1 行ずつ CSV として出力（ヘッダ行の有無はシートの 1 行目に依存） |
| **基準フォルダ** | 前回の保存先などを last_folder で保持し、ダイアログの初期ディレクトリに利用 |

---

## 4. 画面遷移・UI

| 項目 | 内容 |
|------|------|
| **UI 種類** | 保存先選択ダイアログ（名前を付けて保存）、進捗画面、完了通知（ステータスバー・通知） |
| **画面遷移** | Excel リボン → **保存先選択ダイアログ** → **進捗画面** → 完了 → Excel |

### 4.1 各 UI の挙動

| UI | 開くタイミング | 閉じるタイミング |
|----|----------------|------------------|
| **保存先選択** | リボン「CSV保存」で開く | 「保存」または「キャンセル」で閉じる |
| **進捗画面** | 保存先を指定して「保存」を押したあと表示 | 工程 2（完了）表示後、所定時間経過で自動で閉じる。閉じたあと Excel 操作を有効に戻す |
| **完了通知** | 保存完了後 | ステータスバー・シートプロパティ（HC_NOTIFY_RETV）で保存先・行数・容量等を表示 |

### 4.2 進捗の工程

| 工程 | 表示内容 |
|------|----------|
| 1/2 | データ読込中（0%） |
| 2/2 | ファイル保存中 → 完了（100%）→ 所定時間表示後に閉じる |

---

## 5. UI 表示の共通仕様

| 項目 | 内容 |
|------|------|
| **Excel 操作** | 進捗表示中は Excel 操作を無効化（excel_lock）。進捗画面を閉じたあとは有効に戻す |
| **表示位置** | 進捗画面は Excel ウィンドウの中央に表示（config で CENTER_ON_EXCEL 等を指定） |
| **前面表示** | 常に Excel の前面に表示（Excel と親子関係）。他アプリのウィンドウが前面の場合は後ろに隠れる |

---

## 6. 設定・config

| 項目 | 内容 |
|------|------|
| **設定ファイル** | `config/ui_csv_sv.json` |
| **読込タイミング** | 機能起動時（各画面表示時に create_dialog 等経由で読込）。core_cst がファイル mtime でキャッシュ |
| **主な項目** | MAIN.TITLE（保存ダイアログのタイトル）、MAIN.FILTER（ファイル種別フィルタ）、SCREENS.PROGRESS（進捗画面の TITLE / WINDOW 等） |

---

## 7. ログ出力

| 項目 | 内容 |
|------|------|
| **使用モジュール** | `core.core_log`（`get_logger`） |
| **内容** | 保存処理開始・UI サーバへのリクエスト・結果受信・保存成功（ファイル名）等 |
| **フォーマット** | 既存のログ出力に合わせる。出力先は core_log の既定（例: hc_csv.log）に従う |

---

## 8. ファイル名・パス（日本語等）

| 項目 | 内容 |
|------|------|
| **日本語・Unicode** | Windows および本アドインでは、**保存先のファイル名・フォルダパスに日本語（Unicode）を使用できる**。ユーザーが日本語のファイル名・フォルダを指定して保存してよい |
| **注意** | 一部のレガシー環境や他ツールでは Unicode パスで問題が出る場合がある。その場合は英数字のパスを利用すること |
