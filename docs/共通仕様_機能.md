## 2. シートプロパティの共通仕様

### 2.1 定義するプロパティ

Python 側で参照・設定するシートのカスタムプロパティは次の 4 種類のみとする。キー名は **core_stat** の定数で一元管理する。

| キー名 | core_stat 定数 | 用途（意図した使用法） |
|--------|----------------|------------------------|
| **HC_BOOK_NAME** | KEY_BOOK_NAME | ブック名（Excel で一意とみなす名前）。新規シート作成時に set_prop で設定する。 |
| **HC_GUID_B64** | KEY_GUID_B64 | シートを一意に識別する Base64 GUID。新規シート作成時、未設定のときのみ set_guid で設定する。 |
| **HC_STATUS_INFO** | KEY_STATUS_INFO | ステータスバーに表示する文字列。処理中・完了・エラー時に set_status_info で設定する。VBA の RestoreStatBar 等で参照される。 |
| **HC_NOTIFY_RETV** | KEY_NOTIFY_RETV | Python 復帰後に VBA の MsgBox で表示する値。**空なら VBA は何もしない。** |

※ 仕様書等で **HC_NOTIFY_REV** と書かれることがあるが、実装のキー名は **HC_NOTIFY_RETV**（RETV）とする。

### 2.2 使用ルール

- **HC_STATUS_INFO**  
  処理状態・完了メッセージ・エラーメッセージを一貫して **set_status_info** で保存する。取得は **get_status_info**。他モジュールでキー名を直書きしない。

- **HC_GUID_B64**  
  シート識別用。設定は **set_guid**（未設定時のみ）。取得は **get_guid**。core_xlc.find_sheet_by_guid 等で参照する。

- **HC_BOOK_NAME**  
  新規シート作成時に **set_prop(sh, KEY_BOOK_NAME, book.name)** で設定する。キー名は **core_stat.KEY_BOOK_NAME** を使い、リテラル "HC_BOOK_NAME" を直書きしない。

- **HC_NOTIFY_RETV**  
  **通常の完了時には設定しない。特別な時だけ** set_notify_retv を呼ぶ（例: エラー通知、ユーザー設定で VBA の MsgBox を出したい場合）。VBA は RunPython 復帰後に CheckAndNotifyVBA で値を参照し、値があれば MsgBox 表示・表示後に削除する。

上記以外のシートプロパティを本プロジェクトの Python コードで新規に使用する場合は、本共通仕様に追記し、core_stat にキー定数を定義してから用いる。

## 3. VBA へすぐ実行権を戻す（早期復帰）の共通仕様

### 3.1 目的

VBA の RunPython は、起動した Python プロセスが終了するまで待機する。Python が結果を待ち続けるとプロセスが長く生き、Excel のメインスレッドがブロックされ、OS から「無応答」とみなされやすくなる。  
**Python 側だけで**、依頼を渡したあと早く return してプロセスを終了させ、VBA に実行権を戻すことで無応答を抑える。

### 3.2 環境変数と挙動

| 環境変数 | 既定値 | 挙動 |
|----------|--------|------|
| **HC_RETURN_EARLY** | 1 | **1（true/yes/on）**: 依頼を svc_req_*.pkl に書き出したあと、約 1 秒待って **結果を待たずに return** する。Python プロセスが早く終了し、VBA に実行権が戻る。実処理・進捗・完了通知は svc_server および UI 側で行う。 |
| | | **0**: 従来どおり結果ファイル (res_*.pkl) ができるまで待つ。Python 側で例外を受け取りたい場合やテスト・デバッグ時に利用する。 |

### 3.3 実装上のルール

- **hc_main._call_svc_server** で、HC_RETURN_EARLY が有効なときは依頼書き出し → 約 1 秒 sleep → return とする。res_*.pkl の読み取り・例外の伝搬は行わない。
- 実処理は **svc_server**（別プロセス）が従来どおり行う。進捗・完了・エラーは **svc_server および UI（Qt）** で表示する。
- 早期復帰時は結果ファイルが残るため、**古い res_*.pkl の削除**（例: 1 時間以上経過したもの）を hc_main 側で行ってよい。

新規機能で hc_main から svc_server に依頼を渡す場合は、上記の「依頼書き出し → 早期 return（HC_RETURN_EARLY=1 時）」の流れに乗せ、VBA を長くブロックしないようにする。

## 4. 共通モジュール変更時のデグレ防止

共通モジュール（ui_common, core_cst, ipc_file, ui_win, ui_server, svc_host 等）に変更・追加を行った場合は、**他モジュール・他機能で問題が起きていないかの確認が必須**である。確認手順・確認対象一覧は **docs/共通モジュール変更時_デグレ防止.md** に記載する。変更後は必ずこのドキュメントに従い、影響し得る機能（csv_ld, csv_sv, csv_sp, csv_mg, dupli, row_dl, col_dl, dt_ymd, dt_hm）の動作確認を行うこと。

## 5. 元に戻す（Undo）の共通仕様

### 5.1 役割

- **svc_undo**（svc/svc_undo.py）が、キャッシュからの復元（exec_undo）と、復元用スナップショット保存（save_undo_snapshot）を担当する。共通仕様に準拠し、core_xlc / core_stat / core_sys / core_w32 のみ使用する。

### 5.2 保存先と識別

- **保存先**: **core_sys.CacheManager**。実体は Windows 一時フォルダ（%TEMP%）内の **core_cst.CACHE_FILE_NAME**（例: header_converter_cache.pkl）に Pickle で保存される。
- **キー**: `{hwnd}_{pid}_{ブック名}_{シート名}` をファイル名禁止文字で置換した文字列。これによりブック・シートを一意に識別する。
- **ペイロード**: `{"data": list_2d, "book_name": str, "sheet_name": str, "freeze_split_row": int, "freeze_split_col": int}`。exec_undo は `data` をシート (1,1) から write_chunk で復元する。`freeze_split_row` / `freeze_split_col` は保存時点の枠固定（ActiveWindow.SplitRow / SplitColumn）で、復元後に枠固定を再現するために用いる（0 は未使用）。

### 5.3 破壊的処理前のスナップショット保存

- シート内容を上書き・削除する処理（CSV 読込・行正規化・トリム等）では、**ユーザーが確認ダイアログで OK した時点で**、**svc_undo.save_undo_snapshot(book, sheet_id=..., target_hwnd=..., excel_hwnd=...)** を呼び、シートの有効データを保存すること。これにより「元に戻す」で復元可能になる。

### 5.4 Undo情報の扱い（1回だけ戻す）

- **同一キーで1スナップショット**: キーはブック・シートで一意のため、同一ブック・同一シートでは **1 件分のスナップショットのみ** 保持する。
- **上書き**: 新しい Undo 対象の機能（例: hd_nr で「開始」、csv_ld でファイル選択後に読込実行）が **save_undo_snapshot** を呼ぶと、その時点の状態で **上書き保存** される。
- **削除**: **exec_undo** で元に戻した直後に **CacheManager.delete(str_undo_key)** により当該キーを削除する。戻した後は同じ操作で再度 Undo できない。
- **まとめ**: 「直前に実行した 1 つの機能」分だけ戻せる。戻すとスナップショットは消える。別の機能を実行するとスナップショットは新しい状態で上書きされる。

### 5.5 枠固定（FreezePanes）の復元

- 保存時: **save_undo_snapshot** で ActiveWindow.FreezePanes が True のとき、SplitRow / SplitColumn をペイロードに含める。
- 復元時: **exec_undo** でデータ復元・オートフィット後に、一度 FreezePanes = False とし、ペイロードの freeze_split_row / freeze_split_col が 0 でなければ SplitRow / SplitColumn を設定して FreezePanes = True で枠固定を再現する。

### 5.6 表示更新の停止と復元成功時の終了通知

- **表示更新**: **exec_undo** では復元処理（クリア・書込・列幅リセット・オートフィット・枠固定）を **core_xlc.suspend_sheet_updates(ptr_s)** 内で実行し、完了後に表示更新を再開する。
- **終了通知**: 復元に成功した場合、**config/ui_undo.json** の **SCREENS.UNDO_DONE** で定義した完了通知ダイアログを表示する（TITLE, MSG_HEADER, DETAIL_TEXT, BTN_OK, WINDOW 等）。svc_undo が UI サーバへ action=undo_done で依頼し、ui_common が DoneDialog で表示する。

### 5.7 参照

- 実装: **svc/svc_undo.py**（exec_undo, save_undo_snapshot, _make_undo_key）
- キャッシュ: **core/core_sys.py**（CacheManager）, **core/core_cst.py**（CACHE_FILE_NAME）

## 6. モジュールヘッダの History（コード規約）

- 各 Python モジュールの docstring 内 **History** は **最新 3 世代まで** とする。見出しは **「History (latest 3):」** とし、直近 3 件の改訂履歴のみ記載する。古い履歴は追記時に削除する。
