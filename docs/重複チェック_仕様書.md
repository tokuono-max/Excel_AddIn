# 重複チェック 機能仕様書

**対象**: Excel 選択範囲に対する重複検出・着色・レポート表示  
**作成日**: 2026-04-11  
**更新日**: 2026-04-11（最終整合：進捗・ビューポート・設定・§9/§10・改訂履歴）  
**目的**: ユーザーが期待する動きと実装の正本を揃える。現状コードの経緯が不明な場合でも、本書を改訂の基準とする。

**関連モジュール**: `svc/svc_dupli.py`、`ui_qt/ui_dupli.py`、`config/ui_dupli.json`

---

## 1. 機能概要

- **入力**: 指定ブック・シート上の **ユーザー選択** と **UsedRange** の関係に基づく対象セル群  
- **処理**: 仕様に従い「重複」とみなす行またはセルを検出し、シート上をハイライト、一覧レポートを表示する  
- **出力**: 進捗 UI、完了通知、重複検出レポート（モードレス）、ステータスバー文言、ログ

---

## 2. 用語

| 用語 | 意味 |
|------|------|
| **UsedRange** | Excel の `Worksheet.UsedRange` に相当する使用範囲 |
| **有効データ領域** | UsedRange を読み込んだ行列について、**周囲の「セル値が空」とみなせる行・列だけを除いた最小の長方形**（§3.0.1）。左上角は有効データの **上端かつ左端** に一致する |
| **レコード** | 重複比較の1単位。モード A では **同一行について、選択に含まれる各列を列番号昇順で並べた値のベクトル** |
| **重複（行レコード）** | 2 行以上でレコード内容が一致する状態（`keep=False` 相当：同一レコードの行をすべて重複扱い） |
| **重複（セル値）** | 有効データ領域内で、**同一の表示比較キー**（§3.2）が **2 セル以上** に出現する状態（モード B） |

### 2.1 「空」とトリム（有効データ領域）

- **トリム判定の空**: セル値が `None`、または前後空白を除いた文字列が空であるもの（数値 0 は空とみなさない）  
- **書式のみのセル**: UsedRange に含まれるが値が空のセルは、トリム時に「空」として扱う。書式だけが残っている列・行の扱いは **値ベース** とし、Excel 上の見た目だけでデータがあるとはみなさない（必要なら将来「書式も空」の厳密定義を拡張する）

## 3. 対象範囲と選択の解釈

### 3.0 モード分岐（正本・この条件のみ）

分岐条件は次の **2 通りだけ** とする（ほかの条件でモードを割り当てない）。

| モード | 条件 |
|--------|------|
| **モード B** | **左上コーナー選択時のみ**（§3.3 の定義を満たすとき） |
| **モード A** | **モード B 以外**のすべての選択時 |

### 3.0.1 有効データ領域（モード B および基準矩形）

1. `UsedRange` 全体を値として読み込む  
2. **上端・下端・左端・右端**から順に、**その辺がすべて上記「空」である限り** その行または列を落とす  
3. 残った矩形を **有効データ領域** とする。行・列が尽きた場合は対象なし（エラー扱い）

### 3.1 モード A：モード B 以外の選択（連続・歯抜け可）

| 項目 | 内容 |
|------|------|
| **前提** | **§3.0 のモード B 条件を満たさない**選択（単一セル・列・行・部分範囲・複数領域などを含む）。`Selection` と `UsedRange` の **交差** が各 **Area** ごとに取れれば、それら矩形の和集合で解釈する |
| **行・列の対象** | 各交差矩形に含まれる **(行, 列)** のみを「選択されたセル」とする。歯抜け列でも、**行ごとに** その行で実際に選択に含まれる列だけをレコードに含める |
| **レコードの並べ方** | 行番号ごとに、その行で選択に含まれる **列を列番号昇順** に値を読み、1 本のレコードとする |
| **空欄の扱い** | レコード内の空欄同士は **同一** とみなす（`None`・NaN・空白文字列を正規化して比較） |
| **重複判定** | 上記レコード同士を比較し、**完全一致**するレコードが 2 行以上存在すればそれらを重複とする |
| **着色** | 重複と判定された **行について、選択に含まれるセルのみ** をハイライトする（選択していない列は着色しない）。**実装**: 解析後の `hl_rects` を sidecar pickle に保存し、**重複検出レポート表示中**に UI が **ActiveWindow.VisibleRange ± 余白** と各矩形の交差部分だけを Excel 上に着色する（全件一括 COM 着色は行わない）。対象ブック・シートがアクティブでない間は付与済みの表示範囲着色のみクリアする。**負荷・UX**: `VIEWPORT_HIGHLIGHT.POLL_MS` でティック間隔を調整可能。前ティックと **VisibleRange・交差矩形リスト・ジャンプ一時強調セル** が変わらないときは **着色用 COM（ScreenUpdating/Calculation 切替含む）を省略**し、カーソル（砂時計）のちらつきを抑える（§7.1） |
| **レポート** | 重複行を一覧表示。プレビュー用に **先頭 N 列分**（既定 N=3）を文字列化して表示してもよい（判定は全選択列） |

### 3.2 モード B：左上コーナー選択時のみ

| 項目 | 内容 |
|------|------|
| **トリガ** | **左上コーナー選択**であること（§3.3）。それ以外の選択ではモード B に入らない |
| **対象範囲** | §3.0.1 の **有効データ領域** 全体 |
| **重複判定** | 各セルの **表示比較キー**（実装では `UsedRange` から読んだ値を Excel の表示に近い文字列へ正規化して比較。完全なセル `Text` 相当の再現は性能・API の制約により未対応の場合あり）が **2 セル以上** で一致するもの |
| **着色** | 重複値を持つ **各セル** をハイライトする（モード A と同様、レポート表示中は表示範囲＋余白の追従着色。§7.1 のビューポート最適化も共通） |
| **レポート** | 値（表示キー）・代表セル座標・該当セル数など、セルベースで分かりやすい列を定義する |

### 3.3 左上コーナー選択（モード B 判定の唯一の根拠）

- **定義**: Excel の **行番号見出し**と**列文字見出し**の **交点（左上コーナー）** を操作して、**当該シートのすべてのセルが選択された状態**（いわゆるシート全体選択）。これを **左上コーナー選択** と呼ぶ。  
- **モード B**: 上記の **左上コーナー選択時のみ** モード B で重複チェックを行う（§3.0）。  
- **モード A**: 左上コーナー選択 **でない** 選択は **すべて** モード A（§3.0）。例：単一セル・複数セル・1 列だけ・1 行だけ・Ctrl による歯抜け・データ範囲のみの選択など。  
- **COM 実装の目安**（参考）: `Selection.CountLarge` が当該シートの `Cells.CountLarge` 以上、または取得できない環境では `Selection` の行数・列数がシートの最大行・最大列以上、等で **シート全体選択相当**と判定する。  
- **交差が得られない場合**: 左上コーナー選択と判定できるなら **モード B として続行**する。  
- **対象範囲なし**: **モード A** かつ `Selection` と `UsedRange` が **交差しない**、または **有効データ領域が空** → **対象範囲なし**（ユーザー向けメッセージ）。※単一セルのみの選択もモード A のため、データ範囲外の 1 セルなどは **モード B には入らず**、交差なしなら上記メッセージの対象になり得る。

### 3.4 bridge JSON の `selection_areas`（リボン経路）

- **送信**: VBA は `SubmitSvcRequestViaBridge` で `action` が `check_duplicates` のとき、`Selection` が `Range` なら **各 `Areas` について** `Address(External:=True)` を JSON 配列 **`selection_areas`** に格納する（単一矩形・連続選択・Ctrl による歯抜けはすべて **Area 数分の要素**）。`Range` でない（図形・グラフ等）ときは **`selection_areas` を付けない**（従来どおり Python が `Application.Selection` を読む）。
- **受信**: 常駐 `hc_main` が配列を検証し、有効な **非空文字列のリスト**だけを `svc_server` 経由で `check_duplicates(selection_areas=...)` に渡す。
- **解釈（Python）**: 各文字列を **対象ブック**上の `Range` に解決し、**コンテキストシート**（`sheet_id` で解決したシート）と **シート名が一致する Area のみ** を `UsedRange` と交差し、§3.1 と同様の矩形リストに合流する。別シート参照は **スキップ**（診断ログ）。
- **フォールバック**: bridge 由来の交差矩形が **1 つも得られない**ときは **COM の `Selection` 読取**（既存 `_selection_used_rects`）に戻す。
- **左上コーナー選択（bridge 時）**: `Selection` を読まないため、§3.3 の **左上コーナー選択**に相当するかは、bridge 側で渡す情報または **交差後矩形の和集合がシート最大行×最大列の格子を覆うか** 等で近似する。**本書のモード分岐（§3.0）は bridge でも同じ**とし、近似ロジックは実装メモ（§10）に従い追随する。

## 4. 重複検出レポートからセルへジャンプ

### 4.1 現状（実装済み）

- レポートの行に対応するセル（A1 形式）へ移動する（`ui_qt/ui_dupli.py` の `_goto_excel_cell`：`Range.Select`、必要な軸だけ `ActiveWindow`（同一ブック表示時）の `ScrollRow` / `ScrollColumn` で余白付き表示に寄せる、前面化）。

### 4.2 ジャンプ時の見え方（実装方針）

| 項目 | 内容 |
|------|------|
| **目的** | ジャンプ先で **Excel 上の選択** が明確になること（標準の選択表示に任せる） |
| **要件** | `Range.Select`。縦方向が余白付きで収まらないときだけ `ScrollRow`、横だけのときは `ScrollColumn`、両方なら両方（`config/ui_dupli.json` の `GOTO_MARGIN_ROWS` / `GOTO_MARGIN_COLS`）。**`App.activate`** および **前面化**（`SetForegroundWindow`）で Excel にフォーカスを戻す。ウィンドウは **`Windows(1)` 固定ではなく、同一ブックがアクティブなら `ActiveWindow`** を優先する |
| **一時強調** | ジャンプ先セルに **薄いグレー背景**（`GOTO_HIGHLIGHT.BGR`）を付け、**別の行へジャンプする直前**および**レポートを閉じるとき**に解除する。表示範囲追従着色（ビューポートティック）では **重複ハイライト色を塗った後に同じセルへ上乗せ**し、見た目の優先順位を固定する |
| **セル書式** | 重複レポートのジャンプ以外では、セルの **罫線（`Borders`）を COM で変更しない**。一時強調のグレーは上記の範囲に限り **Interior のみ** を用い、解除時は当該セルの塗りを落とす（次ティックで重複色は復帰しうる） |
| **レポート終了時** | レポートを閉じたとき **Excel 操作の有効化** と **前面化** を行い、モードレス枠だけが残って操作できない事象を抑える |

## 5. UI 画面遷移

| 順序 | 画面 | 種別 | 内容 |
|------|------|------|------|
| 1 | 進捗 | モードレス | 読込・解析・レポート用データ準備の進捗（シート着色はレポート表示後の表示範囲追従）。**解析（PHASE_ANALYZE）**中も `svc_dupli` が間引きで進捗 pickle を更新し、長時間処理でもバーが 45% 付近で止まりにくい（モード A / B とも） |
| 2 | 完了通知 | モーダル | 結果サマリ（重複件数など）を OK で閉じる |
| 3 | 重複検出レポート | モードレス | 一覧・セルへ移動・閉じる |

- **pickle 投入順**は **完了通知 → レポート** とし、UI サーバの処理順（mtime 等）と整合させる。

## 6. ハイライト（着色）の解除

| 項目 | 内容 |
|------|------|
| **解除タイミング** | **重複検出レポートを閉じたとき**（Excel に「処理フローとして戻る」最終段） |
| **対象ブック・シート** | `highlight_clear` に **`book_name`（ブック名）と `sheet_name`** を含め、レポート閉鎖時は **処理したブック・シート**上で解除する（アクティブブック／シートが変わっていても誤った場所を触らない） |
| **表示領域着色時** | レポート閉鎖時は **直近で付与した表示範囲内の矩形だけ**を同期解除する（数万 `rects` の全件ループは行わない）。**sidecar**（`rects_path`）は閉鎖時に削除し、**重複チェック開始時**に古い `dupli_hl_rects_*.pkl` を掃除する |
| **Interior** | `color` 解除に加え、`Pattern`／`ColorIndex`／**`TintAndShade`** など塗り関連を落とし、残色を抑える |
| **禁止** | 完了通知の OK 時点では **解除しない**（レポート表示中もシート上のハイライトを維持する） |

## 7. レポート表示仕様（概要）

| 項目 | 内容 |
|------|------|
| **ウィンドウタイトル** | 検出総数をタイトルに含めない（総数は本文ラベルで表示） |
| **行順** | 同一内容グループごとにまとめ、グループは **シート上で若い行番号が先頭のグループから** 並べる |
| **列幅** | 設定で幅 0 の列は内容に応じた自動調整 |
| **モード B のレイアウト** | `req.link_col == 2` のとき `SCREENS.REPORT.MODE_B_WINDOW` をウィンドウ設定にマージ可能（既定より広い `DEFAULT_WIDTH`/`DEFAULT_HEIGHT`、`MIN_WIDTH`/`MIN_HEIGHT`、値列の `VALUE_COL_MAX_WIDTH` と折り返し等）。横見切れの緩和用 |
| **ツールチップ** | 各画面・主要ボタン・テーブル・列ヘッダにツールチップを付与可能（`config/ui_dupli.json`） |
| **前面** | `REPORT.WINDOW` の `EXCEL_FRONT_FOLLOW` / `TOPMOST` により、Excel 前面化や最前面ヒントでレポートを手前に保つ（`ui_qt.ui_common`） |

### 7.1 表示範囲追従（ビューポート）ティック

| 項目 | 内容 |
|------|------|
| **目的** | スクロールに合わせて **表示中の重複セルだけ** Interior で着色し直す |
| **間隔** | `VIEWPORT_HIGHLIGHT.POLL_MS`（ミリ秒。大きいほど COM 頻度が下がり **カーソルちらつきが緩和** されやすいが追従は粗くなる） |
| **余白** | `MARGIN_ROWS` / `MARGIN_COLS` で VisibleRange を拡張した帯と `hl_rects` の交差を塗る |
| **スキップ最適化** | 前ティックと **VisibleRange の四隅**・**今回の交差矩形リスト（`to_paint`）**・**ジャンプ一時強調セル座標** が同一なら、**着色ループと ScreenUpdating/Calculation 切替を行わず return**（軽い COM のみ）。クリア・シート切替・エラー時はキャッシュ無効化 |

## 10. 実装メモ（本書との対応）

| 項目 | 実装状況 |
|------|-----------|
| モード A：歯抜け列・行ごとのレコード | `svc_dupli` で `Areas`×`UsedRange` 交差に基づき構築 |
| モード A：空欄正規化・重複判定 | 正規化後のタプルで `duplicated(keep=False)` |
| モード A：選択セルのみ着色 | `highlight_clear.rects` で解除。着色も同一矩形リスト |
| **モード分岐（本書 §3.0）** | **B＝左上コーナー選択時のみ。A＝それ以外。** `svc_dupli` 1.3.9 で実装追随（bridge 時は COM 全シート判定と交差格子ヒントを OR） |
| モード B：トリガ | **左上コーナー選択（シート全体選択）のみ**（§3.3）。COM は `CountLarge` 等、bridge は §3.4 |
| モード B：有効データ領域 | UsedRange 読込後に行列トリム |
| モード B：表示に近い比較 | 値から正規化した比較キー（完全 `Text` 一致は未保証） |
| 進捗バー（解析中） | `svc_dupli`：`PHASE_ANALYZE` 中、長いループで **間引き `_upd`**（時間＋件数ストライド）。45%〜94% 付近の停滞を緩和（モード A / B） |
| レポートからのジャンプ | 対象 **`book_name` / `sheet_name`** でブック・シート固定。**`Application.Goto(..., Scroll=True)` は使わない**。`Range.Select` の前後で、余白付きで Visible に収まらない軸だけ **`ActiveWindow`（同一ブックがアクティブなとき）の `ScrollRow` / `ScrollColumn`** を更新。同一ブックでなければ `Windows(1)` にフォールバック。Excel 前面化（§4）。**一時グレー**は `GOTO_HIGHLIGHT.BGR`、ビューポートティックで重複色の上に上乗せ |
| ビューポートティック | `ui_dupli`：`VisibleRange`・`to_paint`・goto 強調が不変なら **着色 COM スキップ**。`POLL_MS` は `ui_dupli.json` |
| ハイライト解除 | `highlight_clear.rects` ＋ **`book_name` / `sheet_name`**。レンジ単位で `color`/Interior（`TintAndShade` 含む）をクリア、失敗時は従来の `runs` フォールバック |
| レポート閉鎖 | `enable_excel_window(True)`、前面化、`WA_DeleteOnClose`／`deleteLater` でゴースト枠を緩和 |
| 完了通知（DONE） | 上記と同様に `WA_DeleteOnClose`。OK 時は `hide` 後に `processEvents` を数回回し、**次ティックで `accept`**（同期 `accept` による空枠残りの緩和。csv_sp 系と同方針） |
